# ClearCalc Tools

An original, fast, English-language calculator website built with Astro.

The live site is [https://clearcalc-tools.pages.dev/](https://clearcalc-tools.pages.dev/).

## Commands

- `npm install`
- `npm run dev`
- `npm test`
- `npm run build`

Calculator inputs are processed locally in the visitor's browser. Cloudflare Pages serves the public site. The GitHub Pages copy only publishes noindex redirects to that site.
